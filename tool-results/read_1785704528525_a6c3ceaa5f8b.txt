   182→/// Company-scoped roles. System roles (Owner/Founder/Co-Founder/Investor) are
   183→/// elevated and bypass all permission checks. Custom roles use role_permissions.
   184→model Role {
   185→  id            String   @id @default(cuid())
   186→  companyId     String
   187→  company       Company  @relation(fields: [companyId], references: [id], onDelete: Cascade)
   188→  name          String
   189→  description   String?
   190→  roleTier      String   @default("standard") // elevated | standard
   191→  isSystemRole  Boolean  @default(false)
   192→  systemRoleKey String?  // owner | founder | co_founder | investor | null
   193→  // NOTE: systemRoleKey is unique PER COMPANY (not globally), so every
   194→  // company can seed its own owner/founder/co_founder/investor roles.
   195→  isActive      Boolean  @default(true)
   196→  createdById   String?
   197→  createdBy     Profile? @relation("RoleCreator", fields: [createdById], references: [id])
   198→  createdAt     DateTime @default(now())
   199→  updatedAt     DateTime @updatedAt
   200→
   201→  employees       Employee[]
   202→  rolePermissions RolePermission[]
   203→  invitations     Invitation[]
   204→
   205→  @@unique([companyId, name])
   206→  @@unique([companyId, systemRoleKey])
   207→}

  1496→/// Item Exchange System — tracks a single item exchange request.
  1497→/// An exchange can only be created against an order_item belonging to a
  1498→/// DELIVERED order. Two exchange methods with distinct sequencing:
  1499→///   - courier_replacement: new item dispatched first, courier collects old
  1500→///   - customer_self_return: customer ships old item back FIRST, it's
  1501→///     manually verified, THEN the new item is dispatched
  1502→///
  1503→/// newOrderId/newOrderItemId are nullable — populated only once the linked
  1504→/// exchange order (order_source='exchange') is created, which for
  1505→/// customer_self_return happens LATE (after old item verification).

  1507→/// priceDifference is GENERATED as newItemPrice - oldItemPrice. If positive,
  1508→/// customer owes; if negative, refund due.
  1509→///
  1510→/// "Customer did not return" is a supported terminal outcome — the value of
  1511→/// the never-returned old item becomes a recoverable amount, and Step 2's
  1512→/// server actions will call the existing flagCustomer() with reason
  1513→/// "Exchange item not returned".

  1515→/// NOTE: Managed jointly by Prisma (ORM access) + raw SQL (migration 003).
