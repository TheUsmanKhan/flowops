   291→ACTION 1: createOrganization()
   292→─────────────────────────────
   293→Creates a brand new organization AND its first company together.
   294→Called when user wants a completely new business umbrella.
   295→
   296→  Input:
   297→    org_name: string
   298→    org_logo_file?: File (optional)
   299→    company_name: string
   300→    company_legal_name?: string
   301→    company_logo_file?: File (optional)
   302→    base_currency: string  (e.g. "PKR")
   303→    country_code: string   (e.g. "PK")
   304→    province?: string
   305→    city?: string
   306→    address?: string
   307→    phone?: string
   308→    email?: string
   309→    website?: string
   310→    ntn?: string
   311→    strn?: string
   312→    timezone: string       (default "Asia/Karachi")
   313→    fiscal_year_start: number (1-12, default 1)
   314→
   315→  Server Action steps:
   316→    1. Validate all inputs with Zod
   317→    2. If org_logo_file provided:
   318→       Upload to Supabase Storage:
   319→       'organizations/{user_id}/{timestamp}-logo.jpg'
   320→       Get public URL
   321→    3. Generate unique slug from org_name
   322→       (slugify + check uniqueness, append random suffix if taken)
   323→    4. INSERT organizations row:
   324→       { name, slug, logo_url, owner_id: current_user_id }
   325→    5. If company_logo_file provided:
   326→       Upload to Supabase Storage:
   327→       'companies/{new_org_id}/{timestamp}-logo.jpg'
   328→    6. Generate unique slug from company_name
   329→    7. INSERT companies row:
   330→       { organization_id: new_org.id, name, legal_name, logo_url,
   331→         base_currency, country_code, province, city, address,
   332→         phone, email, website, tax_id: ntn, tax_id_type: 'NTN',
   333→         timezone, fiscal_year_start, created_by: current_user_id }
   334→    8. INSERT 4 system roles for this company:
   335→       - { name:'Owner', system_role_key:'owner', role_tier:'elevated', is_system_role:true }
   336→       - { name:'Founder', system_role_key:'founder', role_tier:'elevated', is_system_role:true }
   337→       - { name:'Co-Founder', system_role_key:'co_founder', role_tier:'elevated', is_system_role:true }
   338→       - { name:'Investor', system_role_key:'investor', role_tier:'elevated', is_system_role:true }
   339→    9. INSERT employees row:
   340→       { company_id: new_company.id, user_id: current_user_id,
   341→         role_id: owner_role.id, status: 'active' }
   342→    10. UPDATE user_settings:
   343→        { active_company_id: new_company.id,
   344→          active_org_id: new_org.id }
   345→    11. If STRN also provided: store separately in company metadata
   346→        or as second tax record (metadata JSONB field)
   347→    12. INSERT audit_log: action='organization.created'
   348→    13. INSERT audit_log: action='company.created'
   349→    14. Return { success: true, org_id, company_id }

   354→Adds a new company to an EXISTING organization.
   355→Called when user already has an org and wants another company under it.
   356→
   357→  Input:
   358→    organization_id: string   (existing org UUID)
   359→    company_name: string
   360→    company_legal_name?: string
   361→    company_logo_file?: File
   362→    base_currency: string
   363→    country_code: string
   364→    province?: string
   365→    city?: string
   366→    address?: string
   367→    phone?: string
   368→    email?: string
   369→    website?: string
   370→    ntn?: string
   371→    strn?: string
   372→    timezone: string
   373→    fiscal_year_start: number
   374→
   375→  Server Action steps:
   376→    1. Validate inputs with Zod
   377→    2. Verify user owns this organization:

   380→    3. Upload logo if provided
   381→    4. Generate unique company slug
   382→    5. INSERT companies row (same as above, under existing org)
   383→    6. INSERT 4 system roles
   384→    7. INSERT employees row (Owner)
   385→    8. UPDATE user_settings to new company
   386→    9. INSERT audit_logs
   387→    10. Return { success: true, company_id }

   391→─────────────────────────────

   393→
   394→  Input:
   395→    company_id: string
   396→    org_id: string
   397→

   408→ACTION 4: getUserWorkspaces()
   409→─────────────────────────────
   410→Fetches all companies the current user is active employee of.
   411→Groups them by organization for the workspace switcher UI.
   412→
   413→  Returns:
   414→    {
   415→      workspaces: [
   416→        {
   417→          org_id: string
   418→          org_name: string
   419→          org_logo_url: string | null
   420→          org_slug: string
   421→          is_owner: boolean  ← user owns this org
   422→          companies: [
   423→            {
   424→              company_id: string
   425→              company_name: string
   426→              company_logo_url: string | null
   427→              company_slug: string
   428→              role_name: string      ← "Owner", "Manager" etc.
   429→              role_tier: string      ← "elevated" | "standard"
   430→              employee_status: string
   431→              is_active_workspace: boolean
   432→            }
   433→          ]
   434→        }
   435→      ]
   436→    }
   437→
   438→  Query logic:
   439→    SELECT employees, companies, organizations, roles, user_settings
   440→    WHERE employees.user_id = current_user
   441→    AND employees.status = 'active'
   442→    JOIN companies ON employees.company_id
   443→    JOIN organizations ON companies.organization_id
   444→    JOIN roles ON employees.role_id
   445→    LEFT JOIN user_settings ON user_settings.user_id = current_user
   446→    ORDER BY organizations.name, companies.name

   480→ACTION 7: archiveCompany()
   481→─────────────────────────────
   482→Archives a company. Owner only. Requires name confirmation.
   483→
   484→  Input: company_id, confirmation_text (must match company name)
   485→  
   486→  Steps:
   487→    1. Verify owner
   488→    2. Verify confirmation_text === company.name
   489→    3. UPDATE companies: is_active = FALSE
   490→    4. UPDATE all employees: status = 'terminated' (access revoked via RLS)
   491→    5. If this was active_company: clear user_settings.active_company_id
   492→    6. INSERT audit_log: action='company.archived'
   493→    7. Return { success: true }
   494→
   495→─────────────────────────────
   496→ACTION 8: archiveOrganization()
   497→─────────────────────────────
   498→Archives entire org + all companies. Owner only.
   499→
   500→  Input: org_id, confirmation_text (must match org name)
   501→  
   502→  Steps:
   503→    1. Verify owner
   504→    2. Verify confirmation_text === org.name
   505→    3. For each company in org: run archiveCompany() logic
   506→    4. UPDATE organizations: is_active = FALSE
   507→    5. INSERT audit_log: action='organization.archived'
   508→    6. Return { success: true }
