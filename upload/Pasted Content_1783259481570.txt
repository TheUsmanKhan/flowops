─────────────────────────────
ACTION 1: createOrganization()
─────────────────────────────
Creates a brand new organization AND its first company together.
Called when user wants a completely new business umbrella.

  Input:
    org_name: string
    org_logo_file?: File (optional)
    company_name: string
    company_legal_name?: string
    company_logo_file?: File (optional)
    base_currency: string  (e.g. "PKR")
    country_code: string   (e.g. "PK")
    province?: string
    city?: string
    address?: string
    phone?: string
    email?: string
    website?: string
    ntn?: string
    strn?: string
    timezone: string       (default "Asia/Karachi")
    fiscal_year_start: number (1-12, default 1)

  Server Action steps:
    1. Validate all inputs with Zod
    2. If org_logo_file provided:
       Upload to Supabase Storage:
       'organizations/{user_id}/{timestamp}-logo.jpg'
       Get public URL
    3. Generate unique slug from org_name
       (slugify + check uniqueness, append random suffix if taken)
    4. INSERT organizations row:
       { name, slug, logo_url, owner_id: current_user_id }
    5. If company_logo_file provided:
       Upload to Supabase Storage:
       'companies/{new_org_id}/{timestamp}-logo.jpg'
    6. Generate unique slug from company_name
    7. INSERT companies row:
       { organization_id: new_org.id, name, legal_name, logo_url,
         base_currency, country_code, province, city, address,
         phone, email, website, tax_id: ntn, tax_id_type: 'NTN',
         timezone, fiscal_year_start, created_by: current_user_id }
    8. INSERT 4 system roles for this company:
       - { name:'Owner', system_role_key:'owner', role_tier:'elevated', is_system_role:true }
       - { name:'Founder', system_role_key:'founder', role_tier:'elevated', is_system_role:true }
       - { name:'Co-Founder', system_role_key:'co_founder', role_tier:'elevated', is_system_role:true }
       - { name:'Investor', system_role_key:'investor', role_tier:'elevated', is_system_role:true }
    9. INSERT employees row:
       { company_id: new_company.id, user_id: current_user_id,
         role_id: owner_role.id, status: 'active' }
    10. UPDATE user_settings:
        { active_company_id: new_company.id,
          active_org_id: new_org.id }
    11. If STRN also provided: store separately in company metadata
        or as second tax record (metadata JSONB field)
    12. INSERT audit_log: action='organization.created'
    13. INSERT audit_log: action='company.created'
    14. Return { success: true, org_id, company_id }

ACTION 3: switchWorkspace()
─────────────────────────────

  Input:

    org_id: string

  Steps:

    3. Return { success: true }

ACTION 4: getUserWorkspaces()
─────────────────────────────
Fetches all companies the current user is active employee of.
Groups them by organization for the workspace switcher UI.

  Returns:
    {
      workspaces: [
        {
          org_id: string
          org_name: string
          org_logo_url: string | null
          org_slug: string
          is_owner: boolean  ← user owns this org
          companies: [
            {
              company_id: string
              company_name: string
              company_logo_url: string | null
              company_slug: string
              role_name: string      ← "Owner", "Manager" etc.
              role_tier: string      ← "elevated" | "standard"
              employee_status: string
              is_active_workspace: boolean
            }
          ]
        }
      ]
    }

  Query logic:
    SELECT employees, companies, organizations, roles, user_settings
    WHERE employees.user_id = current_user
    AND employees.status = 'active'
    JOIN companies ON employees.company_id
    JOIN organizations ON companies.organization_id
    JOIN roles ON employees.role_id
    LEFT JOIN user_settings ON user_settings.user_id = current_user
    ORDER BY organizations.name, companies.name

ACTION 7: archiveCompany()
─────────────────────────────
Archives a company. Owner only. Requires name confirmation.

  Input: company_id, confirmation_text (must match company name)
  
  Steps:
    1. Verify owner
    2. Verify confirmation_text === company.name
    3. UPDATE companies: is_active = FALSE
    4. UPDATE all employees: status = 'terminated' (access revoked via RLS)
    5. If this was active_company: clear user_settings.active_company_id
    6. INSERT audit_log: action='company.archived'
    7. Return { success: true }

─────────────────────────────

  Input: org_id, confirmation_text (must match org name)
  
  Steps:
    1. Verify owner
    2. Verify confirmation_text === org.name
    3. For each company in org: run archiveCompany() logic
    4. UPDATE organizations: is_active = FALSE
    5. INSERT audit_log: action='organization.archived'
    6. Return { success: true }
